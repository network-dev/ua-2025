## Importante

Para que el frontend se conecte correctamente con el backend será necesario modificar el archivo src/config.js con su dirección.

### `npm start`

Ejecuta la aplicación en modo desarrollo.  
Abre [http://localhost:3000](http://localhost:3000) para verla en el navegador.

La página se recargará automáticamente si haces cambios en el código.  
También verás errores de lint en la consola si los hay.

### `npm test`

Lanza el entorno de pruebas en modo interactivo.  
Puedes ver más detalles sobre cómo ejecutar tests en la documentación de tu framework de pruebas.

### `npm run build`

Genera una versión optimizada de la aplicación lista para producción en la carpeta `build`.  
El resultado está minificado y los nombres de los archivos incluyen hashes para mejor gestión de caché.
 
### `npm run eject`

**Advertencia: esta operación no tiene vuelta atrás. Una vez que ejecutes `eject`, no podrás deshacerlo.**

Si no estás conforme con la herramienta de construcción y las configuraciones por defecto, puedes ejecutar `eject` en cualquier momento.  
Este comando moverá todas las configuraciones (webpack, Babel, ESLint, etc.) directamente al proyecto para que puedas modificarlas a tu gusto. Todos los comandos seguirán funcionando, pero ahora apuntarán a estos archivos locales.

No es necesario usar `eject`. Las configuraciones por defecto son suficientes para proyectos pequeños y medianos, pero si necesitas más control, la opción está ahí.
